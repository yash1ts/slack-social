# @slack-social/shared

Shared types and helpers used by [slack-social](https://www.npmjs.com/package/slack-social).

```bash
npm install @slack-social/shared
```

```ts
import { scoreTrending, unicodeForEmoji } from "@slack-social/shared";
```

Requires an npm account that can publish under the `@slack-social` scope (create the org on first publish).
